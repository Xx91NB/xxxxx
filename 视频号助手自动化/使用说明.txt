🎯 视频号助手自动化系统 - 使用说明
====================================

📋 系统简介
-----------
本系统通过语音控制自动点击视频号助手中的"添加商品"按钮。
实现方式：语音识别 → HTTP触发影刀RPA → Python点击指定坐标。

🚀 快速开始
-----------
【方法A：使用批处理文件】
1. 运行 【02_一键启动】start_system.bat
2. 选择"完整启动"模式
3. 说出关键词："添加商品"

【方法B：使用Python启动器】
1. 运行 python run.py
2. 选择"启动语音监听"
3. 说出关键词："添加商品"

📁 文件说明
-----------
【核心文件】
• scripts/shadow_ready.py     - 点击脚本（影刀调用）
• scripts/live_listener.py    - 语音监听脚本
• config/button_coords.txt    - 按钮坐标文件
• config/keywords.txt         - 语音关键词

【启动文件】
• 【02_一键启动】start_system.bat    - 批处理启动器
• run.py                            - Python启动器（推荐）

【工具文件】
• 【01_一键安装】install.bat        - 安装依赖
• 【03_单独测试】test_click.bat     - 测试点击
• 【04_获取坐标】capture_coords.bat - 获取新坐标
• 【05_卸载清理】uninstall.bat      - 清理配置
• 【06_打包发布】make_package.bat   - 打包分发

⚙️ 配置指南
-----------
1. 按钮坐标配置：
   - 运行 【04_获取坐标】capture_coords.bat
   - 或将坐标写入 config/button_coords.txt
   - 格式：X坐标,Y坐标（如：2816,488）

2. 关键词配置：
   - 编辑 config/keywords.txt
   - 每行一个关键词
   - 默认：添加商品、一百八、上链接

3. 影刀RPA配置：
   - 端口：5500
   - 路径：/trigger
   - 方法：POST
   - Python脚本：scripts/shadow_ready.py

🎤 语音使用
-----------
支持的关键词：
• 添加商品（主要指令）
• 一百八（备用指令）
• 上链接（备用指令）
• 可在keywords.txt中添加更多

发音清晰，环境安静时识别率更高。

🔧 故障排除
-----------
【问题1：点击位置不准】
• 解决：运行 【04_获取坐标】重新获取
• 确保浏览器窗口位置和大小不变

【问题2：语音不识别】
• 检查VB-Cable虚拟音频线配置
• 系统声音 → 播放设备：CABLE Input
• 系统声音 → 录制设备：CABLE Output

【问题3：影刀无响应】
• 检查影刀流程是否启动
• 在浏览器访问：http://127.0.0.1:5500/trigger
• 确认端口5500未被占用

【问题4：批处理文件被拦截】
• 使用Python启动器：python run.py
• 或将文件添加到杀毒软件白名单

🔄 更新维护
-----------
• 修改坐标：编辑button_coords.txt
• 添加关键词：编辑keywords.txt
• 更新脚本：替换scripts目录文件
• 重新安装：运行install.bat

📞 技术支持

2. Python依赖是否安装
3. 坐标配置是否正确
