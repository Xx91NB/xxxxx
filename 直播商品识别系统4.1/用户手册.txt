直播商品识别系统 4.1 - 用户指南

📋 系统简介
===========
基于计算机视觉的智能商品识别系统，支持实时视频流和图像的商品检测与识别。

🚀 快速开始
===========
1. 首次使用请运行系统测试：
   python test_all.py

2. 快速启动（推荐）：
   python quick_start.py

3. 或者直接运行主程序：
   python main.py

🎯 功能说明
===========

1. 实时商品检测
   - 使用摄像头实时检测商品
   - 支持多摄像头切换
   - 快捷键：q(退出), s(保存截图)

2. 图像匹配识别
   - 基于ORB特征点的图像匹配
   - 支持从摄像头或文件输入
   - 显示匹配结果和置信度

3. 视频文件处理
   - 处理视频文件中的商品识别
   - 批量处理支持
   - 生成处理报告

4. 屏幕校准
   - 校准屏幕捕获区域
   - 支持鼠标拖拽选择

5. 素材管理
   - 检查素材完整性
   - 统计素材信息
   - 创建示例素材

🔧 系统配置
===========

摄像头配置：
- 默认使用摄像头0，如果无法打开会自动尝试1、2
- 可以在配置文件中修改摄像头ID

模板配置：
- 将商品图片放入 data/images_material/
- 支持格式：jpg, png, bmp
- 文件名作为商品名称

配置文件：
- config/default.yaml - 默认配置
- config/hybrid_mode.yaml - 混合模式
- config/image_mode.yaml - 图像模式
- config/video_mode.yaml - 视频模式

🛠️ 常见问题
===========

Q1: 摄像头无法打开
A: 系统会自动尝试摄像头0、1、2，请确保：
   - 摄像头已正确连接
   - 没有被其他程序占用
   - 尝试重启程序

Q2: 图像匹配效果不好
A: 请检查：
   - 模板图片是否清晰
   - 商品角度是否一致
   - 光照条件是否相似
   - 可以尝试调整匹配参数

Q3: 程序运行缓慢
A: 可以：
   - 降低摄像头分辨率
   - 减少匹配模板数量
   - 关闭实时预览

Q4: 导入模块失败
A: 请运行：
   pip install -r requirements.txt
   或
   pip install opencv-python numpy pyyaml
